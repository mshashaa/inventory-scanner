# Inventory Scanner

A small browser-based inventory counter for iPhone and desktop testing.

## Use on iPhone

1. Open the GitHub Pages URL in Safari.
2. Tap Share, then Add to Home Screen.
3. Open Inventory Scanner from the Home Screen.
4. Tap Start camera and allow camera access.

Scanned items, product names, and counts are stored locally on the device. Export downloads an Excel-compatible `.xls` file.
